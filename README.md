# Taahira Carter — Portfolio

Personal portfolio website showcasing Applied AI builds, production support expertise, and operational platforms.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React + custom SVG brand icons
- **Deployment:** Static export (compatible with Vercel, Netlify, AWS Amplify, etc.)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```

## Deployment

This site is statically generated and can be deployed to any static hosting provider.
